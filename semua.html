💻 BAGIAN 2: TERMINAL - pwd, cd, dir

CARA BUKA: HP = Aplikasi Termux. Laptop Windows = Windows+R ketik cmd.

pwd = Gue dimana?

pwd
Nunjukin lu lagi di folder mana. Contoh: /home/budi

ls / dir = Liat isi folder

ls
dir
ls = Linux/Termux, dir = Windows. Fungsinya sama: liat apa aja di folder ini. ls -a = liat semua termasuk yang disembunyiin

cd = Pindah Folder (PALING PENTING!)

cd Documents
cd ..
cd ../..
cd /
cd ~
cd Documents=Masuk Documents, cd ..=Mundur 1 langkah, cd ../..=Mundur 2 langkah, cd /=Balik ke paling awal, cd ~=Balik ke Home

mkdir = Bikin Folder

mkdir game-baru
Bikin folder baru namanya game-baru

touch / echo = Bikin File

touch catatan.txt
echo "Halo Hacker" > halo.txt
touch=bikin file kosong. echo > = bikin file + isi.

cat / type = Baca File

cat halo.txt
type halo.txt
cat=Linux, type=Windows. Buat baca isi file.

rm / del = Hapus (HATI-HATI!)

rm halo.txt
rm -r game-baru
del halo.txt
rm=hapus file, rm -r=hapus folder + isinya, del=Windows. Kalau udah dihapus gak bisa balik!

cp / mv = Copy / Pindah

cp halo.txt halo2.txt
mv halo.txt nama-baru.txt
cp=copy, mv=pindah/ganti nama. Di Windows: copy dan move.

clear / cls = Bersihin Layar

clear
cls
clear=Linux, cls=Windows.

🌐 BAGIAN 3: JARINGAN - ipconfig, ping, netstat

IP = Alamat rumah di internet. Contoh: 192.168.1.5=HP lu, 192.168.1.1=Router WiFi lu, 8.8.8.8=Google, 127.0.0.1=Diri sendiri.

ipconfig = Liat KTP Internet Lu

ipconfig
ipconfig /all
ifconfig
ipconfig=Windows, ifconfig/ip a=Linux/Termux. Cari: IPv4 Address=IP lu, Default Gateway=IP Router lu.

ping = Teriak HALO! Dibales gak?

ping google.com
ping 8.8.8.8
ping 192.168.1.1
Reply time=15ms=BERHASIL! Makin kecil makin cepet. Request timed out=GAGAL! ATURAN: Ping Router dulu. Kalau ke Router gagal, WiFi lu yang rusak. Kalau ke Router berhasil tapi ke Google gagal, internetnya yang mati.

netstat = Siapa aja yang nyambung?

netstat
netstat -an
LISTENING=Lagi nunggu. ESTABLISHED=Udah nyambung, lagi ngobrol. Kalau ada ESTABLISHED ke IP aneh yang lu gak kenal, waspada!

tracert = Lewat jalan mana?

tracert google.com
traceroute google.com
tracert=Windows, traceroute=Linux. Nunjukin paket lu lewat mana aja sampe ke Google.

nslookup = Nanya IP nya Google

nslookup google.com
Nanya ke DNS: google.com itu IP berapa? DNS=Buku telepon internet.

arp -a = Siapa aja di WiFi gue?

arp -a
Liat semua HP yang nyambung ke WiFi yang sama. Kalau ada yang gak kenal, bisa jadi ada yang numpang WiFi!

LATIHAN JARINGAN:

1.Cek IP gue -> 2.Router nyambung gak? -> 3.Google nyambung gak? -> 4.Siapa aja yang nyambung? -> 5.Siapa aja di WiFi gue?
